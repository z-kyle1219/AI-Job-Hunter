# Job Hunter · Design System

> 取代仓库根目录的 `DESIGN-SPEC.md`（v1.0 黑白编辑风）。这一版是「现场导视」：白纸、整片信号黄、墨黑粗体、巨大数字。
> 实现：`src/styles/system.css`（唯一样式入口）。旧 `tokens.css / global.css / pages.css / *.css` 已不再被引用。

---

## 1. 原则

1. **一屏一个决定。** 每块屏只回答一个问题，答案用最大号字写在最上面。
2. **方向靠箭头，不靠进度环。** 「向前 N 屏」「下一步」比百分比更像现场。
3. **作废不抹掉。** 失效岗位留在名录里，划线，仍然可读。
4. **一屏最多一块黄，落在要做决定的地方。** 黄是牌，不是场地：可以一条带、一块判决、一列推荐，也可以整屏没有。铺满整屏是不允许的。

## 2. 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--yellow` | `#F6C700` | 每屏唯一的一块黄：底带、判决块、完成度面板、推荐列 |
| `--yellow-deep` | `#E0B400` | 黄上的次级描边（极少用） |
| `--ink` | `#111111` | 正文、主描边、主按钮底、黑带 |
| `--paper` | `#FFFFFF` | 纸面 |
| `--wash` | `#F6F4ED` | 列表 hover 底 |
| `--mute` | `#6E6A5E` | 次级文字（白底 5.4:1） |
| `--line` | `#E3DFD2` | 分隔线 |
| `--hair` | `rgba(17,17,17,.22)` | 黄底上的分隔线 |
| `--red` | `#C0392B` | 只给失败、来源失效、解析失败 |

**禁止**：紫色系；黄与另一个饱和色同屏大面积出现；渐变、发光、玻璃拟态；阴影。

## 3. 字体

| 角色 | 字体 | 规格 |
|---|---|---|
| 数字 / 拉丁 / 编号 | `Bahnschrift`（回退 `DIN Alternate` / `Segoe UI`） | 600–700，`tabular-nums` |
| 中文与正文 | `Segoe UI` → `PingFang SC` → `Microsoft YaHei` | 400–800 |

字号档位：`92 / 52 / 34 / 30 / 19 / 16 / 15 / 14 / 13 / 12 / 11`
类名：`.q`（问题，最大）、`.h1`、`.h2`、`.h3`、`.lead`、`.small`、`.eyebrow`、`.num`。

**规则**：数字永远比它旁边的中文大一个档位以上；问题句用 `.q`，一屏只有一个。

---

## 4. 间距与形状

- 左右内边距 `--pad: clamp(20px, 5.2vw, 88px)`；页顶 `--top: 64px`。
- 间距只用 4 的倍数：`8 / 16 / 24 / 32 / 48 / 64 / 96`。
- **圆角只有一种**：`.pill` 的 `999px`（可点控件）。其余一律直角。
- 分隔靠 1px / 1.5px 线，不靠阴影。
- 黑带 `.band` 固定在视口底部：左侧「步数 / 总数 + 当前位置」，右侧 4 格刻度 + 下一步胶囊。

## 6. 状态

| 状态 | 表达 |
|---|---|
| 已核验 / 仍在招 | 实心黑点 + 「已核验 · 仍在招」 |
| 待核验 | 空心黑点 + 「待核验 · 未回访」 |
| 来源失效 | 红色空心点 + 标题划线 + 「来源失效 · 已关闭」 |
| 后端未连接 | 小字写明地址 + 本地估算 + 「重试」胶囊 |
| 空态 | 一句直白的话 + 一个动作，不画插画 |

## 7. 动效

- **开场序列**（只在首屏发生一次）：
  1. 全白，只有两行标题在正中，字在乱码翻动（约 `1.15s` 落定）。
  2. 两块黄牌从左往右抹开，`0.76s`，缓动先快后慢（`cubic-bezier(.16,1,.3,1)`）。
  3. 标题带着轻微过冲滑回最终位置（`0.95s`，`cubic-bezier(.22,1.14,.3,1)`）；同一刻其余文字、排版、左上角小 logo 依次淡入（延迟 `0.04 / 0.12 / 0.2 / 0.28s`）。
- 页面是真滚动，不劫持滚轮、不做整屏切换。
- **开头只播一次**：模块级标记 `introPlayed`，从别的页面回到 `#/intro` 时直接给终态（黄牌已上、文字全在），不会再把标题甩到视口中央。
- 其余只用两件：行 hover 反白（`160ms`），箭头右移 `8px`。
- 无滚动进场、无视差、无自动轮播。
- `prefers-reduced-motion: reduce` 时全部静止：直接出终态，一字不差。

## 8. 首次进入的三屏

| 屏 | 内容 | 出口 |
|---|---|---|
| 1 | 开场标题 + 底部一条登录（手机号 / 邮箱） | 「进入」或「跳过，先看看」 |
| 2 | 个人档案：目标岗位 / 城市 / 期望类型 | 「保存，进入主页」或「跳过」 |
| 3 | 三块，一条线 + 黑带 | 「填写档案 →」进上传页，或「先看看主页」 |

顶部不再放登录键；账户入口只留在主页的顶栏。

---

## 9. 文案

- 标题说清「解决什么」：今天先解决哪一步？/ 哪个值得投？
- 按钮是「动词 + 对象」：从简历开始、生成定制简历、去模拟面试。
- 不写「赋能」「一站式」「AI 驱动」；分数旁边必须能点开依据。
